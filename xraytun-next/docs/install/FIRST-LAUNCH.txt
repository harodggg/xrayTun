XrayTun Next · 首次打开请看这里
================================

这个 App **没有 Apple 开发者签名（未公证）**，所以从网上下载后第一次双击，
macOS 会弹一句「无法打开，因为 Apple 无法检查其是否包含恶意软件」。
那是系统对「没公证」的默认拦截，不是文件损坏。

用下面任意一种方式打开
----------------------

方式一（最快）：
  1. 把 XrayTun.app 从磁盘映像拖到「应用程序」文件夹；
  2. 在「应用程序」里**按住 Control 点它（或右键）** → 选「打开」；
  3. 弹出的对话框里再点一次「打开」。之后就能正常双击了。

方式二（系统设置）：
  1. 先双击一次（会被拦）；
  2. 打开「系统设置 → 隐私与安全性」，往下找到关于 XrayTun 的那条，
     点「仍要打开」；
  3. 再双击一次，确认。

方式三（终端，等价于去掉「来自网络」的隔离标记）：
  xattr -dr com.apple.quarantine /Applications/XrayTun.app

打开之后怎么用（最短路径）
--------------------------

1. 「节点」页：把机场给的**订阅原文**或一串**分享链接**粘进输入框，点「导入」；
   或者去「设置 → 订阅」填订阅 **URL**，点「添加订阅」（这条会联网拉取）。
2. 回到「节点」页，在你要用的那一行点「选为当前节点」。
3. 回「仪表板」，按那个大的「启动」按钮。
   第一次会让你装**特权助手**（TUN 模式需要它建 VPN 网卡、改路由与 DNS），
   会弹一次系统管理员授权 —— 那一步是必须的，取消授权就没法启动。
4. 收工时按「停止」；想彻底清干净就去「设置」里**卸载特权助手**
   （界面会写清删掉哪几样、留下哪一个目录）。

出问题时看哪里
--------------

* daemon 日志：~/Library/Logs/XrayTun/xt-daemon.log
  （日志里不写订阅 URL 的路径与令牌，只写到主机名 —— 贴给别人看之前仍建议自己扫一眼）
* 界面上的错误都是**原样**给的（错误码 + 原始说明），不会改写成「请重试」之类的空话。
* 如果界面说「连不上 daemon」，它下面会附一句壳的报告（为什么没起来）+ 上面那个日志路径。

已知边界（这个版本**不是**完整产品）
------------------------------------

* 只有 TUN 一种模式（没有 SOCKS/代理模式的入口）。
* TUN 的真机接管（授权弹窗、utun、路由与 DNS 提交）**没有经过验收**；
  CI 上装不了 launchd 守护服务，这几步只能在你这台机器上验证。
* 未公证 ⇒ Gatekeeper 的行为以你真机为准；杀毒软件也可能拦截被装的助手。
