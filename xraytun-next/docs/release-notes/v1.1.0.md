# xraytun-next v1.1.0 · 首个 macOS 应用包（TUN 模式）

**预发布 / 未公证。** 这是 xraytun 平行重写（`xraytun-next-v1` 分支）第一个**能在 macOS 上安装的 .app**。
它包含 TUN 模式（特权 helper + daemon 两阶段接线），但**尚未经过真机验收**。

## 资产

| 文件 | 内容 |
| --- | --- |
| `XrayTun_1.1.0_universal.dmg` | macOS 桌面应用（Tauri 2 壳，universal：x86_64 + arm64；内嵌 xray + xt-daemon + xt-helperd）|
| `xraytun-next-1.1.0-macos-universal.tar.gz` | macOS 核心 CLI（xt-daemon + xt-cli，universal）|
| `xraytun-next-1.1.0-linux-x86_64.tar.gz` | Linux x86_64 核心（xt-daemon + xt-cli）|

## 诚实声明（务必读）

1. **未经公证**：本包是 ad-hoc 签名，没有 Developer ID 签名 + 公证（S5 需要 Apple 凭据）。
   Gatekeeper 会拦「未识别开发者」，双击打不开时解除：
   ```bash
   xattr -dr com.apple.quarantine /Applications/XrayTun.app
   ```
2. **运行时未验证**：TUN 是否真的接管流量、helper 安装/回滚、菜单栏交互，都**未在真机验证**（S6）。
   这是「能装上、能启动」，**不是「已证明能用」**。请在真机验收并反馈问题。
3. **TUN 模式尚未宣告**：`Capability::TunMode` 要等真机验收通过后才宣告，所以界面当前
   只开放 proxy 模式；TUN 开关被能力门控隐藏。

## 从 v1.0.0 到 v1.1.0 的增量（S1–S4）

- 新增 macOS 系统网络原语层 `xt-macosnet`（utun / 地址 / 路由 / DNS / 快照回滚）。
- 新增特权 helper `xt-helperd`（root 守护 + SecCode 对端校验 + 封闭指令集）。
- daemon 接入 TUN 两阶段流程（`TunUp → TakeTunFd → spawn xray → CommitRoutes`）。
- 新增 Tauri 2 桌面壳 `apps/desktop`（菜单栏 + 主窗口 + daemon IPC 桥）。
