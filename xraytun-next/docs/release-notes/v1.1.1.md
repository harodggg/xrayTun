# xraytun-next v1.1.1 · 修复：daemon 元数据全「未知」

## 修了什么

**症状**（真机 S6 首次运行）：app 能装、能开，但顶栏报
`invalid_request: hello 只能发一次`，daemon 版本 / pid 全「未知」，设置页「设置未加载」。

**根因**：Tauri 壳的桥（`apps/desktop/src/bridge.rs`）用 `xt_ipc::Client::connect`
连 daemon 时，**内部已经替 UI 做过一次 `hello` 握手**；而 UI 的 tauri 传输层又按
`DaemonClient` 契约发了一次 `hello`。daemon 只接受一条连接上的**第一条** `hello`
（`xt-daemon/src/lib.rs`：第二条回 `invalid_request`），于是整条连接在 UI 看来是坏的。

**修法**：桥在本地**吸收** UI 的 `hello` / `subscribe` —— 直接返回已协商好的
`Client::hello()` 与成功应答，**不再转发**给 daemon。
