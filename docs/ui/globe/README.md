## 默认视角的取舍（改过一版）

第一版把「让两端都进画面」理解成「把那 1° 撑满屏幕」，于是广州↔香港这种
129 公里的近邻航线被放大到接近上限 —— 球占满画布、只剩一片海岸，反而看不出
「从哪飞到哪」。

现在的规则是：**装得下就不放大**。所以近距离航线默认看到整个地球，
只有跨半球时才自动缩小。要看细节由用户滚轮放大。

## 缩放范围

上限 1.8 倍是按「球缘要看得见」定的：球半径是画布短边的 0.42，
再放大球缘就溢出画布、失去方位感。

## 验证方式

量缩放时**读画布自身的像素**（`getImageData`），不用截图 ——
球放大后会撞到画布边界被裁剪，看截图的宽度会得到「没变化」的错误结论。
