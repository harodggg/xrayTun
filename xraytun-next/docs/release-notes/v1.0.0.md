## 边界（如实说）

* **能用**：proxy 模式下的 连接 / 断开 / 切节点 / 真实流量统计。
* **不能用**：macOS TUN、特权 helper、远端订阅拉取（http/https）、Tauri 图形界面（本包不含 UI）。
* 切节点是「选择就用」：失败就停在失败并报真实原因，**不会**自动换下一个节点；不自动重连、不重试。
* 未采样时 `stats` 为 `null`，界面/CLI 显示「未采样」—— 绝不用 `0` 顶替。
* 本包只有 `linux-x86_64`。macOS 上的任何二进制**都没有构建、也没有验证**。
