## 给用户的动作：**本版不需要重装特权助手**，但**必须换成这个新 App**

依据（可复算）：

```bash
git diff --stat v0.8.45..v0.9.0 -- crates/xt-helper crates/xt-tun crates/xt-proto
# → 三个 helper 侧 crate 零改动
grep -n 'PROTOCOL_VERSION' crates/xt-proto/src/lib.rs     # 4（与 v0.8.45 相同，未变）
```

协议号未变、helper 侧可观察行为未变 ⇒ 装不装助手都能用新 App。
`crates/xt-core` 只有一处注释改动，不改变任何可观察行为。

> 诚实边界：**站点上的旧版本包不会自动消失**。装新版本请从本页下方下载，不要用旧包覆盖。

## 这一版改的是「界面跟上内核」

0.8.x 已经把内核层的诚实做得很硬了：崩溃回滚、会话快照、两阶段启动、五档状态色、假按钮清零。
0.9.0 不做那些，而是**把它们推到界面上**，一句话：

> **每个动作都有回声 · 每句文案都说人话 · 信息不靠颜色 · 状态不说谎 · 操作少等一次**

### 1. 改设置只有一种心智：改完就生效，而且能撤销

以前设置页是「改 → 点保存 / 放弃」，而分流预设和顶栏模式是「改一下就生效」。
用户从设置页学到的「要保存」在别的页不成立，于是要么以为没生效，要么以为已经生效。

现在设置页**逐项自动保存**：拨一下开关就落盘，并出现一行 `已保存「X」` + 一颗**撤销**。
撤销是真的 —— 它会把上一个值再存一次。文本框有 400ms 静默窗口，离开输入框立即落盘。

* 保存**失败**时不会说「已保存」，也不会拿旧设置去重启核心（那会让你看到一个假的成功）。
* 连续改两次**都会落盘**：忙的时候是**排队**，不是把后一次丢掉（丢掉意味着界面显示新值、
  磁盘还是旧值 —— 这类「静默吞掉你的改动」是本次专门修掉的）。
* 「重启核心才生效」的提示按原样保留。

### 2. 换节点不再一声不响

换节点会拆掉旧隧道再建新的，中间几秒是断的。以前界面全程安静，你会以为点了没用、于是重复点。

现在会出现一行进行中提示：**正在切换到「你点的那台」——隧道会重建…**，完成即收。
**刻意不加二次确认** —— 换节点是高频动作，每次都问一句才是真的烦。

### 3. 拓扑图不再只靠颜色分类

图上四种流向原来只用颜色区分，而实际那几条线在深色底上只有 1.15–1.93:1 的对比度 ——
**图例承诺的四种颜色，图上是看不出来的**（这既是可读性问题，也是"界面陈述了不实事实"）。

现在四种流向各有**线型**（实线 / 虚线 / 点划线 / 长点线），**图例改成真实线段的缩影**：
颜色、线型、线宽、透明度与图上完全一致。灰度截图、色觉障碍、低质量投影下都能读出分类。
只改了描边样式，线的位置与动画一行没动。

### 4. 日志等级加了一个字符

每行开头多一个字母：`E` / `W` / `I` / `D`（未知等级 `·`）。它拼在已有的等宽时间戳列里，
**没有新增列、也没有新增 DOM 节点**，所以行高与对齐不变。同样是给不能靠颜色区分的场景。

### 5. 失败时留下的陈述更诚实

「断开」时如果回滚网络配置失败，以前只弹一次瞬时错误就过去了 —— 而看门狗自愈、换网那两条路
都会留下一条持久说明。**同一种失败，一条路说实话、另一条不说，这本身就是缺陷**。

现在失败会在界面上留下一条持久说明，**带着 helper 给的真实原因**，并明确写「**未能确认网络已恢复**」，
再给你「修复网络（回滚遗留配置）」的入口。它**不会**再说「网络可用」—— 那是我们没验证过的事。

### 6. 新用户少点一步、少猜一次

- 还没有任何节点时，仪表盘的主按钮**直接就是「添加订阅」**并落到订阅页
  （以前一律是「选择节点」，而「去订阅页加订阅」这句话只写在节点页里 —— 你得先点错一次才知道）。
- 「helper」第一次出现时会带上「（特权助手，安装时需要管理员密码）」。
- 「哨兵 DNS」改名叫 **「隧道内 DNS 地址（哨兵）」**（它仍在明面上，因为它的说明正是
  「隧道没了而 DNS 还指着它 ⇒ 表现为全网断」这条风险的提示）。
- 侧栏「规则」改叫 **「分流」**，与页内标题一致（「自定义规则」保留原词 —— 你会搜这个词）。

### 7. 拓扑页与地球仪：真实数据优先

- **拓扑页**：「最近连接」提到车流图**之前**；「某个网站走哪条路」与「生效规则链」搬到
  **分流页**（拓扑页段落从 4 段降到 2 段），并保留一个从拓扑到分流判定区的入口。
- **地球仪**：事实面板与错误说明提到画布**之前**；**主数字从「大圆距离」换成「累计流量」**
  （距离是最不可行动的字段），距离降为次要。文案里不再出现「速率」，改成「与当前网速无关」。

### 8. 顺手修掉的

- **`Esc` 关闭**拓扑连接详情、节点导出、日志诊断三处面板（macOS 习惯）。
- 动画不再每帧每车查一次 DOM（实测原来 662 次/秒），并补了一条**颜色断言** ——
  此前 25 条拓扑测试里一条颜色断言都没有，这类回归无人接住。
- 删掉 14 处冗余内联间距；补上两个**写了但根本没定义**的样式类
  （`note--warn` / `banner--muted`，用了 5 处 ⇒ 空操作，和以前那次「分隔线从未渲染」同族）。

## 内部（你无感，但决定了这一版能不能被验证）

- 新增 **journey 级用户测试**：从「用户点一下」到「屏幕上出现什么」整条路断言，
  每条都配反向判据（防止"文案存在但说错对象"这种假绿）。
- 全量：**67 个测试文件 / 630 条通过**（上一版基线 568 条），构建与样式 token 校验全过。
- `apps/desktop` 在 Linux + Rust 1.98.1 上通过 `cargo check` / `clippy -D warnings` /
  新增单测（这是本项目为"按需云端编译"建的那条通道，跑完即删）。
- ⚠️ 诚实边界：**真机 macOS 行为未验证**（开发机不是 macOS）。
  `⌘,` 打开设置、helper 授权、TUN 建卡与回滚、换节点真实耗时都需要你在真机上用一次。
