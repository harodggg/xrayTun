# 拓扑页的视觉迭代记录

这一页改了四轮，每轮都用 CDP 量几何或采样像素来核对，而不是只看截图。

| 文件 | 阶段 | 关键改动 |
|---|---|---|
| `01-highway-links.png` | 最终 | 入口汇聚 → 车道 → 分流到出口的连线；车道垂直居中 |

## 迭代过程中量出来的问题

1. **车道被顶在上边**：实测车道高 66px、出口列高 415px，`align-items: start`
   让车道孤零零挂在左上角。改为居中后，左右两列与车道中心偏差小于 3px。
2. **连线穿越卡片**：用 `querySelectorAll` 取入口时把「合计」行也算进去了
   （4 个 vs 3 条车道），连线被摊开成斜线穿过卡片。改用按渲染列表构造的
   明确引用数组，并把起止 y 对齐到入口行，连线变成水平线，只从卡片
   之间的空隙穿过。
3. **层级核对**：一度怀疑线压住了文字，用像素采样确认卡片区域是
   `rgb(22,29,44)`（不透明），覆盖层 z-index 0 < 车道 1 < 卡片 2 ——
   层级本来就是对的，问题是线的走向，不是层级。

## 一处刻意的口径

连线表达的是「汇入同一条主干、再分流」这个**结构关系**（来自配置事实），
而不是「入口 i 对应车道 i」。四条车道是同一个规则链前面的队列；核心只有
按入口/按出口两类统计，没有逐条规则的计数器。车道颜色用的是同一套口径。
