## 这一版修的最重要一件：**意图页整页黑屏**

真实事故（用户机器上抓到的原文，已带 `file:line:col`）：

```
undefined is not an object (evaluating 'm.ads_intent.toFixed')
  @tauri://localhost/assets/index-DlAlD2vo.js:58:3435
```

根因是**后端契约与前端类型不符**：`AuditRecord` 的 8 个可选字段带着
`skip_serializing_if = "Option::is_none"` —— `None` 时 **key 整个消失**；而前端 TS 类型写的是
`number | null`，代码只判 `=== null` ⇒ 实际拿到 `undefined` ⇒ `.toFixed()` 抛异常
⇒ React 卸载整棵树 ⇒ **界面黑屏，且一个字的报错都看不到**。

触发条件比预想的宽：审计里只要有**一条没被打分的行**（例如 `deferred`），意图页就整页崩。

### 三层修复

1. **后端契约**：除 `context_sent` 外，可选字段一律发**显式 `null`**（不再省略 key）。
   `context_sent` 保留省略是**刻意**的：默认配置下审计文件里连 key 都不该出现
   （`the_context_is_absent_by_default` 就是这条隐私不变式）。后端只保证**新写的行**。
2. **前端容错（第二道保险，而且是必需的）**：新增 `fmtProb`，判据是
   `typeof === "number" && Number.isFinite(v)`。**只改后端救不了历史数据** ——
   磁盘上的旧审计行永远是缺 key 的，`JSON.parse` 得到的就是 `undefined`。
3. **类型不再说谎**：`IntentAuditRecord` 的可选字段改成可选（`?`），让 TS 类型与线上实际一致。
