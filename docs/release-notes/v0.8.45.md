## 给用户的动作：**本版不需要重装特权助手**

依据（可复算）：

```bash
git diff --stat v0.8.44..v0.8.45 -- crates/xt-helper crates/xt-tun crates/xt-proto
# → 只有 crates/xt-proto/src/transport.rs +55（全是 #[cfg(not(target_os = "macos"))] 的 stub）
git show v0.8.44:crates/xt-proto/src/lib.rs | grep PROTOCOL_VERSION   # = 4
git show v0.8.45:crates/xt-proto/src/lib.rs | grep PROTOCOL_VERSION   # = 4（未变）
```

协议号未变、helper 侧可观察行为未变 ⇒ 装不装助手都能用新 App。

## 这一版修的都是你亲身遇到的问题

### 1. 切换节点"看起来没用"——界面以前在误导你

你选中香港节点时，若它不可用，App 会**自动回落到另一个能用的节点**（这个行为是对的），但界面顶栏**只显示"你选的"**，于是你看到"我切到香港了，出口却还是美国"。

现在：顶栏同时给出两个事实 —— `实际在用：XrayTun-US（你选的：Xray-45.207.197.185）`，并有一条**可见横幅**说明「本次实际用了哪个、为什么换、**你的选择没有被改动**」；仪表盘同样区分；节点列表里坏节点带 `egress-broken`（或 `tcp-unreachable`）类别、**上次失败时间**、告警条与「本次回落未使用」标签，删除入口照旧。

> 诚实边界：App **不能**让一个不可达的节点变得可达；能保证的是不再让你误以为"切换生效了"。

### 2. 「内核与更新」这一屏不再有"假按钮"

- **已装版本就是最新时，不再出现「更新核心到 vX」**，改为一句话结论「核心已是最新（vX）」——以前"查到了"就等于"有新版"，按钮点了白跑一趟。**读不到版本时如实显示"未知"**，既不谎称已最新、也不静默隐藏。
- **geo 编号不再印两遍**（`v26.9.9 v26.9.9` 的根因在后端写盘处，已修）。
- **一屏只剩一颗主按钮**（优先级：客户端 > 核心 > geo，其余降级但保留入口）；没有新版就不渲染动作按钮。
- **决定你敢不敢点的事实与按钮同屏可见**：「不会改动 App 包本身」「回退 = 删掉那些文件，永远可用」「核心更新需要重新连接核心才会生效」「客户端更新会退出并重启 App，请先断开隧道」；开发者细节（预发布策略、配额说明、`SHA256SUMS.txt`、日志路径）收进默认收起的「细节」。
- 五个更新操作的**忙碌文案不再只显示"有操作正在进行…"**（内部键名与文案表对齐，并加了防复发的守卫）。
- 顺手修掉：`.kv` 样式被定义两次导致的**键值交错**（仪表盘/路由/设置三处受影响）、内核路径与数据目录现在**等宽 + 可复制**（失败有可见反馈）、TUN 提示改为**按实际支持情况**显示（不再无条件劝你升级核心）。

### 3. 「报告问题」出包在 App 里**必然失败** —— 已修（但只有本版包才生效）

根因不是脚本逻辑，而是**打包时漏拷了两个运行期文件**（`helper_tristate.py` 与 `fixtures/`），于是随包脚本 import 不到。现在：新增一份**运行期依赖清单**，打包时按清单补齐并逐条校验（漏一条拒绝出货），脚本入口也按清单做前置检查；`metrics.json` 的失败原因会写进包内（不再只留一句"见 metrics.err"而那个文件又被删掉）。

> ⚠️ 你机器上**已安装的旧 App 仍会失败**——仓库里的修法回填不了已安装产物，必须装本版。

### 4. 站点：App 起不来时也有得看

站点新增（已上线）中英排障页 `https://xraytun.top/troubleshoot/`：怎么确认真是崩溃（`abort() called`）、`panic.log` 在哪（含 `XRAYTUN_DATA_DIR` 覆盖的情况）、日志怎么交给我们、可直接照做的命令；并明确写下：**「先把系统代理关掉试试」不会让它启动，只会让别的程序一起断网**、**不要为了排障去改系统 DNS / 路由**。

### 5. 内部（用户无感）

macOS 专有的 socket 接口按 `target_os` 门控，非 macOS 平台返回明确的"仅 macOS 可用"错误（**不削弱 helper 的安全门**：真正的对端校验路径不经过这些函数）。这让**平台无关的 crate 能在 Linux 上编译**，于是编译可以搬到按需开启的云机器上跑，跑完即删。
