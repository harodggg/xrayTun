## 为什么「车道」与「连线」曾经对不上

早期把两者分成两层：车道是带货车的容器（CSS 动画让车左右漂），连线是覆盖层。
结果是**货车只在自己那条车道里往返，和连线没有关系** —— 看着像两套不相干的东西。

现在一条路线就是**一条连续路径**（入口 → 车道 → 扇出 → 出口），货车用
`getPointAtLength` 沿它从头走到尾；车道那一列只作为「道路」的视觉底衬。

两个实现要点（都踩过）：

* 路径必须是**一条连续路径**：每段各写一个 `M` 会得到多段互不相连的子路径，
  而 `getPointAtLength` 只沿一条路径连续采样 —— 货车会在段与段之间跳。
* 动画的起始时刻要放在 ref 里：拓扑每 2 秒刷新一次会重建 effect，
  用局部变量会让货车**每 2 秒跳回起点**。

## 车道列为什么最后被删掉

用户要求「车道应该消失，线本身应该就是车道」—— 这反而让布局更简单：

* 从四列（入口 / 车道 / 扇形列 / 出口）变成**三列**（入口 / 流动区 / 出口）；
* 车不再「在车道里漂」，而是沿**完整的路线**（入口 → 汇入 → 扇出 → 出口）走，
  连线与货车因此天然在同一层；
* 删掉了 `.lane` / `.lane-wrap` / `.highway__road` / `.highway__links` 等一批样式
  （那一段还遗留了三处同名规则互相覆盖）。

## CSS 上的两个硬教训（都是量出来的）

1. **同名规则的后者优先**：把 `grid-column` 追加到文件末尾，结果被后面的
   `.highway__legend` 覆盖 —— 图例占了第 1 列，入口卡片被挤到第 2 列，
   整幅图错位。定位必须写在**同一个规则块**里。
2. **整页有 `max-width: 820px`**：先用两个空白占位列（32px + 128px）给弧线留空间，
   流动区被压到 374px、卡片文字开始裁切。弧线空间要在**流动区内部**预留，
   不要单独占列。

## 一处刻意的口径

连线表达的是「车道与出口相连」这个**结构关系**（来自配置）。
核心只有按入口 / 按出口两类统计，**没有逐条规则的计数器**，
所以**不**声称「这辆车的货去了哪个出口」。出口怎么分给车道是为了画得清楚，
不代表真实流量走向。

## 教训

8 版才定下来的原因，多数是**凭观感调**而不是**先量**。
后来每次先量一次，就立刻发现一个具体数字问题（4px / 10px / 84px），
比反复看截图快得多。另外：自己写的路径解析正则会算错，改用 `getBBox()`。
