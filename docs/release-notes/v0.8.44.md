## 给用户的动作：**本版需要重新安装特权助手（一次管理员授权）**

本版又把 `PROTOCOL_VERSION` 从 **3 升到 4**。原因和上一版同一条，但这次是新的改动落在 helper 里：

- `31b47b0` 改的是 `crates/xt-tun/src/macos/route.rs`（capture 路由的 `replaced` 精确匹配）——**那是 helper 里的代码**；
- 不升号的话，已经装过 0.8.43 助手的机器（协议 3）会被判成"版本匹配"、**不会提示重装**，于是拿不到这个修复，而且**完全无声**。

⇒ 界面会提示助手版本不匹配 → 点「**重新安装助手**」。

> **建议直接从 0.8.44 起步**：如果你还没装 0.8.43，直接装本版只需重装一次助手；如果你已经装了 0.8.43，本版会**再提示一次**——这是对的，不是折腾你，是老助手确实不含这个修复。

判据（可复算）：

```bash
git diff --stat v0.8.43..v0.8.44 -- crates/xt-helper crates/xt-tun crates/xt-proto   # 非空
git show v0.8.44:crates/xt-proto/src/lib.rs | grep PROTOCOL_VERSION                  # = 4
```

## 这一版新增

### 1. 「观察（只观察、不改写）」接进界面 —— 你终于能把内容"拿出来看"

「意图过滤」页 → MITM 卡片：

- **开关默认关**；域名名单**默认空**（空 ⇒ 一条摘要都不写，绝不自动填你没点名的域名）；
- 点「应用」后按域名汇总标记词命中，例如 `promoted × 3 · is_ad × 1`；
- 能看到的：host、方法、去 query 并截断的路径、状态、content-type、body 字节数、短哈希、标记词计数；
- **默认不落盘任何正文**；只有你显式填**绝对路径**才会把 `<hash>.body` 写到仓库外（权限 0600，相对路径会被拒绝并给出原因）；
- 未开启 / 名单空 / 名单非空但零命中，三种空态分别成句，且都写明「**没有证据 ≠ 干净**」，**绝不显示成"没有广告"**；
- 页面固定列出**看不到什么**：h2/HTTP3(QUIC)、WebSocket（回 501）、证书固定/不信本地 CA 的站点、上游强制压缩体、`Expect: 100-continue`、超过 12 MiB 的体。摘要里**没有完整 URL / query / 正文**。

它的用途是回答"广告响应里到底有没有机器可读标记"：**有标记 ⇒ 用确定性规则拦**（免费、毫秒、可解释）；**没标记 ⇒ 才谈本地 ONNX 分类器**。先有数据，再选武器。

### 2. 回滚不再把半个 IPv4 表钉在物理网卡上（`0/1 → en0` 残留）

- `route -n get -net <前缀>` 实测**不是**精确前缀查找：它会按内核最长前缀匹配返回**别的**路由（实测 `/1` 会拿到另一张网的 `/1`，`/32` 甚至拿到 `0/1` 捕获路由）。
- 旧实现据此把 capture 路由（`0/1`、`128/1`）的 `replaced` 记成物理网卡那条 ⇒ 回滚时"恢复"成 `0/1 → en0`，**半个 IPv4 空间被钉在物理网卡上**：代理在用时可导致**流量绕过隧道（泄漏）**，代理不在时也会改变直连路径。现场日志里有该行证据。
- 现在改成解析 `netstat -rn` 按「**网络号 + 前缀长度都相等**」精确匹配，并顺带修好旧实现查不到的 `/32` 主机路由、以及真机键 `128.0/1` 被误报"缺失"的问题；解析失败一律 fail-open（宁可漏一次恢复，也不造残留）。

> 诚实边界：本版**只止血，不清理历史残留**——如果你的表里已经有旧版本留下的 `0/1 → en0`，精确匹配会正确地把它当成"被覆盖的路由"并在回滚时恢复它。**如果你还看到这条残留，告诉我**，我加一步主动清理。
